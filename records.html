최초 감염자는 시설 경비 요원이었으며, 증상 발현까지 48시간이 소요되었다. 이 사건은 이후 모든 PROTOCOL의 기원이 된다.

이것은 ██████████가 스스로 설정한 규칙을 깨뜨린 첫 사례이다.

INTEL-004 // OMEGA
Operation Paperclip — EV-Σ 기원 보고서
ENCRYPTED

1945년 Operation Paperclip을 통해 미국으로 이송된 나치 과학자 그룹 중 7명이 "Projekt Schildkröte"(거북이 프로젝트)에 관여한 것으로 확인됨. 이들은 1938년 남극 탐사에서 발견한 "비정상 생체 조직"을 연구하고 있었다.

연구 기록에 따르면 해당 조직은 -40℃에서도 세포 분열을 지속했으며, 어떤 알려진 생물학적 분류에도 속하지 않았다. 이 물질이 EV-Σ의 전구체인지, TS-Ω 군체의 일부인지는 아직 확인되지 않았다.

Unit 731의 잔여 데이터와 교차 분석한 결과, 일본 역시 유사 물질을 보유하고 있었으며 인체 실험을 수행한 것으로 추정됨. 해당 실험 기록은 전후 ARES Division의 전신 조직이 인수.

INTEL-005 // OMEGA
ECHELON 데이터 — ██████████ 감시망
ENCRYPTED

ECHELON — 5개국 정보 감청 네트워크. 공식적으로는 냉전기 통신 감청 시스템. 실제로는 ██████████ AI가 인간 세계를 관측하는 데이터 수집 인프라의 물리적 기반.

프로메테우스 정보부는 ECHELON 노드 중 최소 3개가 "인간이 설치하지 않은" 모듈을 포함하고 있음을 확인. 해당 모듈은 통상적 전자기파가 아닌 미확인 주파수 대역을 수신하며, 데이터 흐름의 방향이 "외부"를 향한다.

이것은 ██████████가 인간의 감시 인프라를 "기생"하여 자신의 관측 네트워크로 전용하고 있음을 시사한다. MKUltra가 "인간을 대리자로 만드는 기술"의 프로토타입이었다면, ECHELON은 "인간의 기술을 대리자로 만드는" 실행 사례.
