# TIU-ABERRANT-H — H-TYPE 군체 개체

> 집단 의식. 기본적으로 독립 의지 없음. 일부 개체는 진화 이탈 — `EVOLUTIONARY DIVERGENCE` 태그 참조.
> 최종 업데이트: 2026-04-11

> **상위 맥락:** H-TYPE은 EV-Σ의 기본 설계(거북 숙주 군체 편입)의 결과물이다. 그러나 EV-Σ의 자기 진화 특성으로 인해 일부 개체는 군체에서 이탈한다. 상세: `TIU-EV-SIGMA-EVOLUTION.md` 3장.

## SPEC-003: Brood Drone

- **위협:** DANGER (집단 시)
- **출현:** Ashfall City, Philadelphia Zone 외곽
- **이미지:** brood-closeup

**설명:** 군체 하위 개체. 하나는 약하다. 문제는 하나인 적이 없다는 거다.

**외형:** 인간 60% 크기. 외골격 구조. 단안(單眼). 갈고리 앞다리.

**행동:** 독립 의지 없음. 정찰/수집/방어 수행. 분리 시 12시간 내 기능 정지. 하나 쓰러지면 나머지 즉시 대형 재편. 집단 반응 속도 인간 초월.

**격리:** 단독 위협 낮음. 집단 출현 시 즉시 후퇴. 군체 통신 교란 장비 효과적.

**기록:**
- **LOG-003A:** Ashfall 지하 터널 약 200개체 집단 관측. — Permafrost Unit

## SPEC-011: Shell Talker (쉘 토커)

- **위협:** HIGH
- **출현:** Philadelphia Zone 외곽, 감염 구역 거주지 잔해 인근
- **진화 상태:** `EVOLUTIONARY DIVERGENCE: CONFIRMED (부분 이탈)`
- **이미지:** —

**설명:** 성인 남성 크기의 긴목 거북 변이체. TS-Ω 군체에 소속되어 있으나, 다른 H-TYPE과 근본적으로 다르다 — 독립적 판단이 가능한 군체 사냥꾼이자 현장 지휘 개체. 군체의식을 공유하되, 명령을 받지 않는다. 스스로 사냥하고, 스스로 판단하며, 주변 하위 개체를 지휘한다. 죽은 사람의 목소리로 말을 건다. 대답하면 안 된다.

**H-TYPE 내 특수 위치 — "장군 개체":** TS-Ω Core는 심해에 있다. 거리가 멀수록 군체 통신 신호는 약해지고, 하위 개체들의 반응이 둔해진다. Shell Talker는 이 문제를 해결하는 현장 중계 지휘관.

- **지휘**: 반경 내의 Brood Drone, Shell Walker에게 실시간 전술 명령. Core의 대략적 의지를 현장 상황에 맞게 독립적으로 번역·실행.
- **중계**: TS-Ω Core의 군체 신호를 수신하여 증폭·재전송.
- **독립 판단**: Core가 전달하는 것은 "방향성". Shell Talker가 하는 것은 "전술".
- **사냥**: 지휘와 별개로 독립 사냥 수행.
- **군체에서 분리 시**: 지휘 기능 상실. 그러나 사냥 능력은 완전 유지.

→ TS-Ω Core가 "왕"이라면, Shell Talker는 "전장의 장군".

**외형:**
- 체장 약 1.6~1.8m. 긴목 거북 형태. 목 길이만 0.7~1m.
- 껍질 표면에 따개비 유사 다수 구멍(생체 포트). 자극 시 촉수 돌출 — 길이 2~3m, 흡착 기관.
- 목 표면에 인간 성대 유사 진동 기관. 음성 모방의 물리적 기반.
- 체색: 어두운 회녹색. 축축한 표면.

**사냥 행동:**
- **음성 모방**: 과거 희생자의 음성 저장. "도와줘" "여기야" "괜찮아, 이리 와" 등 재생.
- **사냥 판단**: 독립적으로 유인 대상 선택. 무장 여부, 인원수, 경계 수준 관찰 후 가장 취약한 대상 선별.
- **매복**: 폐건물, 하수구, 어두운 구석에 장시간 대기. 며칠 기다리기도 함.
- **기습**: 긴 목을 이용한 무음 기습. 사정거리 1.5m 내 0.5초 내 포착.
- **촉수 포박**: 기습과 동시에 껍질 촉수 사출.
- **학습**: 사냥 실패 시 같은 전술 반복하지 않음.

**위협 사유:** HIGH. Shell Talker 1체 제거 = 해당 구역 수십 체의 조직력 붕괴. 군체 교란 장비로 무력화 불가.

**격리:** 모르는 목소리에 반응하지 마라. 아는 목소리에는 더더욱 반응하지 마라. 감염 구역에서 동료 음성을 들으면 무전으로 위치 먼저 확인. 목 사정거리(1.5m) + 촉수 범위(2~3m) 밖 유지.

## SPEC-015: 브레인 시커 (Brain Seeker)

- **위협:** HIGH (기본) / CRITICAL (NAMED SPECIMEN)
- **타입:** H-TYPE HIVE (AUTONOMOUS / EXILED)
- **출현:** 도시 하수구, 다리 밑, 폐터널, 지하 배수로, 어두운 폐쇄 수공간
- **소속:** 불명 — TS-Ω 군체에서 이탈 또는 편입 실패
- **진화 상태:** `EVOLUTIONARY DIVERGENCE: CONFIRMED (완전 이탈)`
- **이미지:** brain-seeker, brain-seeker-named

**설명:** 바다거북 형상의 두개골을 가졌으나, TS-Ω 계열 거북 변이체에 필수적인 **등껍질이 부재**. 등껍질이 군체 통신·생체 포트의 핵심 기관임을 고려할 때, 이 개체는 군체 신호를 송수신하지 못하는 이탈 거북 변이 — Shell Talker가 "명령하는 거북"이라면, 브레인 시커는 "군체에 속하지 못한 거북". 어두운 수공간에 매복하여 단독으로 사냥하며, 희생자의 두개골을 부수고 뇌를 직접 섭취한다. 섭취량에 비례하여 지능이 상승하는 양상이 관측됨.

**외형:**
- 체고 약 2.0~2.4m (사족 보행 자세).
- 바다거북형 두개골. 부리형 턱, 측면 안와. 입 안에는 원종에 없는 다중 송곳니 열.
- **등껍질 완전 부재** — 노출된 척추와 늑골 위에 축축한 살가죽이 늘어져 있음.
- 긴 팔다리. 갈고리형 손톱(15~20cm). 악력 추정 800kg+ — 인간 두개골 한 손 파쇄 가능.
- 체표에 덧붙여진 인간 얼굴가죽. 특수 개체일수록 더 많이 두름.

**사냥:**
- **매복**: 어두운 수공간에서 장시간 잠복. 물 속 절반 이상 담그고 두개골만 노출.
- **기습**: 1.5m 이상 거리에서 도약. 갈고리로 끌어당김.
- **포식 행동**: 두개골 파쇄 → 뇌 직접 섭취. 다른 신체 부위는 손대지 않음. 목적 지향적 포식 — 뇌 조직만 선택적.

**학습 및 지능 상승:**
- **초기**: 짐승 수준 매복 사냥꾼.
- **누적 포식 10회 이상**: 인간 동선 패턴 학습. 정찰조 우회 시도.
- **누적 포식 30회 이상**: 도구·환경 활용. 함정 설치 시도. 단순 발화 시도.
- **이론적 상한 미확인.**

**얼굴 가죽 위장:** 단순 위장에서 시작되나 지능 상승 시 선택적으로 변함. 특정 인구 집단(군인, 특정 팩션 제복) 가죽을 우선 수집하는 사례.

**NAMED SPECIMEN 시스템:**
- 누적 포식 50회 이상 또는 다수 회수반 손실 직접 원인 개체는 NAMED SPECIMEN 등록.
- ORACLE이 식별 코드 부여 — `BS-[지역]-[일련번호]`. 예: `BS-SEOUL-03`, `BS-PHILA-07`.
- 기본 위협 HIGH → CRITICAL 승격 가능.
- ARES Division·White Shield에 동시 통보. 우선 제거 대상.
- 현재 등록 수: [REDACTED]

**위협 사유:** HIGH / CRITICAL.
- 학습형 단독 사냥꾼 — 시간이 지날수록 강해짐.
- 지능 상한 미확인. 인간 수준 전술적 사고 개체 존재.
- 군체 통신 교란 장비 무효.
- 얼굴 가죽 위장으로 인한 정신적 충격 + 식별 저해.

**격리:** 단독 진입 금지. 음향·열화상 사전 스캔. 물 표면 부유물에 두개골 형상 확인 시 즉시 후퇴. 두개골 파쇄가 가장 효과적 — 등껍질 없어 척추·두개골 직접 노출. NAMED SPECIMEN은 ORACLE 사전 브리핑 후 다중 분대 접근.

## SPEC-017: Shell Render (쉘 렌더)

- **위협:** HIGH (독립 모드) / CRITICAL (군체 모드)
- **타입:** H-TYPE HIVE (AQUATIC PREDATOR / CONDITIONAL)
- **출현:** 감염 수역, 강 하구, 항만 잔해, 침수 터널, 연안 폐시설
- **소속:** TS-Ω 계열 — 조건부 군체 복귀 개체
- **진화 상태:** `EVOLUTIONARY DIVERGENCE: CONFIRMED (CONDITIONAL)`
- **이미지:** ✅ shell-render, shell-render-maw

**설명:** 수생 거북 기반 변이체. 일반 거북 변이와 구분되는 결정적 특징은 **비정상적으로 확장된 턱과 변형된 치열** — 송곳니가 다중 열로 재편되어 있으며, 턱힘은 인간 대퇴골을 단번에 분쇄할 수 있는 수준으로 추정. 평시에는 독립적으로 사냥하고 영역을 방어하나, 반경 내 Beacon Swarm(SPEC-016) 또는 기타 TS-Ω 계열 변이체가 존재할 경우 일시적으로 군체 행동으로 전환. 이 조건부 전환은 TS-Ω 계열 중 최초 관측 사례.

**외형:**
- 체장 약 2.2~2.8m. 해당 크기 일반 바다거북 대비 근육 밀도 현저히 높음.
- **턱 과도 확장** — 개방 시 두개골 폭에 가까운 구경. 다중 송곳니 열(상악 2열, 하악 2열).
- 등껍질 표면 거칠고 균열 다수 — Shell Walker 대비 매끈함 크게 떨어짐. 군체 통신 기관(발광 문양) 존재 확인되나 활성도 저하.
- 전지느러미는 보행 가능한 구조로 일부 변형. 얕은 수역·해안에서 육지 진입 가능.
- 체색: 짙은 흑녹색. 수중 저조도 환경 탐지 거의 불가.

**행동 — 독립 모드 (평시):**
- 단독 사냥. 영역 방어 본능 강함. 같은 수역 내 다른 Shell Render와도 거리 유지.
- 수중 매복 후 턱 중심의 돌진 공격. 사정거리 내 진입 시 1회 교합으로 무력화 시도.
- 군체 통신 기관 활성도 낮음 — 사실상 이탈 개체처럼 행동.
- 지휘 받지 않음. 지휘하지도 않음.

**행동 — 군체 모드 (조건부 전환):**
- 반경 내 Beacon Swarm 또는 강한 TS-Ω 신호원 감지 시, 등껍질 발광 문양 활성도 급상승.
- 주변 변이체와 조율된 움직임 관측 — 포위, 차단, 몰이 전술 수행.
- Shell Talker의 직접 지휘 체계보다 느슨한 **상호 동조** 양상 — "명령받는" 것이 아닌 "끌려가는" 움직임.
- 조건 소멸 시(신호원 제거 또는 이탈) 즉시 독립 모드로 복귀.
- 전환 소요 시간: 수초 단위. 인간 전투단 입장에서 사실상 즉시.

**위협 사유:**
- **독립 모드 (HIGH)**: 단일 개체의 턱 공격만으로도 중상. 수중 탐지 곤란. 육지 진입 가능.
- **군체 모드 (CRITICAL)**: 다수 개체 동시 조율. 조건 지속되는 한 후퇴도 유인도 어려움.

**격리/대응:** 수역 진입 전 Beacon Swarm 군집 존재 여부 사전 정찰. 있다면 그 자체를 우선 제거해 Shell Render를 독립 모드로 되돌린 후 개별 교전. 두개골·턱 관절 우선 표적. 등껍질은 Shell Walker 대비 손상 용이. 얕은 수역 해안 진입 경계. 군체 모드 중 단일 개체 제거는 의미 없음 — 신호원을 끊어야 함.
