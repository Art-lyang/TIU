# TIU-ABERRANT-S — S-TYPE 확산 개체

> 광역 확산 기능. 고정형 또는 비실체. 최종 업데이트: 2026-04-11

> **상위 맥락:** S-TYPE은 EV-Σ 확산의 핵심 벡터. 일부 개체는 단순 확산을 넘어 군체 신호 인프라 기능까지 수행한다. 상세: `TIU-EV-SIGMA-EVOLUTION.md`.

## SPEC-004: Seed Spreader

- **위협:** CRITICAL
- **출현:** Silent Belt (러시아), 확산 경계 지역
- **이미지:** ✅

**설명:** 고정형 확산 개체. 움직이지 않는다. 그럴 필요가 없다. 바람이 대신 운반해준다. 동충하초가 개미 한 마리를 조종한다면, 이것은 도시 하나를 조종한다. **Silent Belt 형성의 주요 원인.**

**외형:** 높이 2~4m. 식물 유사하나 내부에 맥동하는 생체 조직. 상부에서 불규칙 포자 구름 방출.

**행동:** 이동 안 함. 반경 수km 포자 확산. 포자 노출 유기체의 행동 변형 (동충하초 메커니즘).

**격리:** 반경 500m 접근 금지. 제거 시 소각 + 토양 오염 처리 병행. 포자 흡입 = 즉시 감염. **제거 시 폭발적 포자 방출(2차 확산) 위험.**

**기록:**
- **LOG-004A:** Silent Belt 경계 최초 발견. 주변 3km 내 모든 동물 사라짐. 새 한 마리도. — Permafrost Unit
- **LOG-004B:** 소각 시도. 파괴 순간 포자 폭발 방출. 4명 즉시 감염. → 방호복 의무화. — 사후 보고

## SPEC-008: Spore Phantom

- **위협:** CAUTION
- **출현:** 포자 밀집 지역 (Silent Belt 내부)
- **이미지:** —

**설명:** 안개 속에서 사람처럼 걸어온다. 조명을 비추면 흩어졌다가 — 더 가까이에서 다시 나타난다. 1994년 오크빌에 내린 "젤리 비"가 이것이었을 수 있다.

**외형:** 포자 집합체가 인간형 실루엣 형성. 실체 불명. 빛에 분산 → 어둠에서 재형성.

**행동:** 직접 공격 능력 불명. 접근 시 포자 농도 급격 상승. 흡입 위험.

**격리:** 조명 유지. 방독면 필수. 실체 없음 → 물리 제거 불가. 포자 밀도 저감만 가능.

**참고:** 1994년 오크빌 블롭스(Oakville Blobs) — 워싱턴주 젤리 비. 대기 확산형 가능성.

## SPEC-016: Beacon Swarm (비컨 스웜 / 표식 군)

- **위협:** CAUTION (직접) / CRITICAL (전략)
- **타입:** S-TYPE SPREADER (신호 증폭형 수중 부유체)
- **출현:** 감염 해역, 조류 유입 해안, 항만 잔해, 얕은 연안 수역
- **이미지:** ✅ beacon-swarm, beacon-swarm-shoal

**설명:** 해파리 형태의 변이체. 돔형 몸체 표면에 격자 무늬의 발광 기관이 배열되어 있으며, 이 발광 기관이 TS-Ω 군체 명령 신호를 수신·증폭·재전송하는 **생물학적 신호 중계기**로 기능한다. ORACLE은 이 개체를 단독 생물이 아닌 "수중 군체 통신 인프라의 구성 요소"로 분류한다 — 그래서 기계 용어 "Beacon Swarm"이 공식 명칭으로 채택되었다.

**외형:**
- 돔 직경 약 0.6~1.2m. 개체 크기 편차 있음.
- 돔 표면에 격자형 발광 기관 — 정사각형 패턴의 청백색 광점.
- 촉수 다수. 길이 1.5~2.5m. 끝단까지 약한 발광.
- 체색: 투명에 가까운 회흑색. 광점이 없으면 수중 시각 탐지 어려움.
- 자체 이동 기관 존재하나 기능 미약 — 관측상 조류·파도에 의한 수동 이동이 주.

**행동:**
- **신호 증폭**: 주변 TS-Ω 군체 신호를 수신, 격자 발광 기관을 통해 광학·전기 신호로 재방출. 단일 개체 범위는 제한적이나, 군집 시 기하급수적 확장.
- **수동 이동**: 자체 수영 거의 전무. 조류에 운반됨.
- **군집 형성**: 단독 관측 거의 없음. 수십~수백 개체가 동일 수역에 동시 표류.
- **마비독**: 촉수 접촉 시 약한 신경독. 단일 접촉은 손 저림 정도. 군집 특성상 다수 접촉 빈번 — **누적 마비로 수영 능력 상실 가능**. 조난자 익사가 주 사망 원인.

**전략적 영향 — 왜 CRITICAL인가:**
Beacon Swarm이 점거한 해역에 진입한 다른 EV-Σ 변이체는 TS-Ω 군체 신호 수신 강도가 대폭 상승한다. 평시 독립적으로 행동하던 조건부 이탈 개체(→ SPEC-017 Shell Render)가 Beacon Swarm 영향권 내에서는 **군체 모드로 강제 전환**되는 양상 관측. 즉, Beacon Swarm 자체의 직접 전투력은 낮으나, 그 존재만으로 수역 내 변이체 생태계의 행동 양식이 근본적으로 바뀐다.

> ORACLE 논평: "이 개체는 무기가 아니다. 이것은 환경이다. 무기가 되는 것은 이것이 있는 수역에 있던 다른 모든 것이다."

**제거/대응:**
- 물리적 파괴 용이. 격자 발광 기관 파손 시 신호 중계 기능 상실.
- **소각 시 2차 위험 없음** — Seed Spreader와 달리 포자 방출 구조 부재.
- 군집 규모가 크면 개별 제거 비현실적. 해역 자체 봉쇄가 효과적.
- 방호 잠수복 + 절연 장비 권장. 맨손 접촉 절대 금지.
- 연안 작전 시 Beacon Swarm 밀집 수역 = "신호 오염 구역" 사전 분류.
