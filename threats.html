EVOLUTION PHASES

Phase 0 이후에는 법적 지위, 가족 접근, 자산 처리까지 함께 변동된다.

PHASE 0

DORMANT

외부 증상 없음. 혈액·단백질 표지만으로 탐지 가능. 격리보다 신속한 확인과 추적이 핵심이다.

PHASE 1

SURFACE

표면 변이가 시작된다. 일부 사회 통합 사례가 있으나, 직장·학교·가족 신고 의무가 충돌한다.

PHASE 2+

STRUCTURE

생체 구조 재편, 분열, 포자 방출 가능성. 면회·재산·사망 처리 기준은 국가별로 다르다.
