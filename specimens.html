SPECIMENS

SPEC 색인은 변이체를 “괴물”이 아니라 대응 가능한 패턴으로 기록한다. 공개본은 식별명, 위험도, 현장 금지, 민간 피해 비용을 제공한다. 발생 원인과 심층 계보는 봉인되지만, 현장에서 어떤 선택을 해야 하는지는 이 페이지에서 확인할 수 있다.

PUBLIC SPEC TYPES

국가별 호칭은 다르지만, 현장 대응에서는 행동 패턴이 우선된다. 아래 항목은 한국 지부와 카드게임 공개 기록에서 확인 가능한 표면 색인이다.

SPEC-001

감염체 마네킹

정지 시 인체와 구분이 어렵다. 3m 내 자극 시 0.3초 안에 공격 전환 가능. 단독 접근 금지.

SPEC-003

Brood Drone

군집형 하위 개체. 독립 의지는 낮지만 핵 개체 지시에는 빠르게 반응한다. 분리 전 소모전 금지.

SPEC-008

Spore Phantom

포자·광반응형. 광원 조건에서 분산되며 흡입 노출 시 개인 문제가 가족 단위 격리로 확대된다.

SPEC-011

Shell Talker

실종자나 가족의 목소리를 모방한다. 피해자 음성 확인 시 문을 열거나 단독 응답하지 않는다.

SPEC-012

Blood Pit

환경 오염형. 붉은 점액질과 소화효소로 유기물을 분해한다. 회수품 반출과 증거 보존이 충돌한다.

PHASE 0

Latent Host

외견상 일반 시민. 감염 기록은 삭제되지 않고 접근권 제한으로 처리된다. 보험·취업·면회권에 영향을 준다.
