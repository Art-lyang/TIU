# KR-INIT-001 ORACLE SYSTEM MANUAL

오라클 AI를 운용하는 한국지부 신규 지휘관이 필요한 고유명사와 표면 정보를 빠르게 확인하기 위한 소규모 랜딩페이지입니다.

## 파일

- `index.html` — 정적 단일 페이지
- `css/kor-init.css` — 기존 `tiu-archive` PA-TERMINAL 디자인 토큰을 재사용한 전용 스타일
- `js/kor-init-i18n.js` — 한국어/영어/일본어 전환용 전용 번역 레이어
- `js/kor-init.js` — 용어 필터와 교본 요약 복사 기능
- `assets/specs/` — 카드게임 SPEC 고화질 이미지 사본

## 공개 범위 원칙

- 신규 지휘관이 공개 교본과 운용 아카이브에서 열람해도 되는 `PUBLIC/HINT` 정보 위주로 작성했습니다.
- 페이지에 등장하는 인물명, 지명, 기업명, 조직명, SPEC명은 `1. 세계관` 원본 문서 또는 카드게임 이미지 자산에서 확인 가능한 것만 사용합니다.
- 출처가 확인되지 않은 이름은 예시·플레이스홀더·디자인 목업 안에서도 사용하지 않습니다.
- 상위 시스템 표기는 일반 시민에게 알려진 기관처럼 설명하지 않고, 게임 UI 또는 고권한 로그의 인터페이스 층위로만 처리했습니다.
- 기원급 기록, 상위 구조, 외부 지역의 내부 진상, 고대 배치 정보는 노출하지 않았습니다.
- 한국지부 정론은 2033 아카이브 기준의 과거 기능정지 기록으로 처리했습니다.
