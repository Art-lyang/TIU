오라클 한국지부 운용 목표

01

오라클 명령 우선

기지는 ORACLE 지시와 분류를 최우선 운용 기준으로 삼습니다. 현장 판단은 명령 해석을 보조하되, 충돌 시 상위 명령 확인 절차를 따릅니다.

02

한국지부 안정화

KR-INIT-001 관련 인력, 시설, 보고 체계를 안정화합니다. 권한 이탈, 로그 불일치, 지휘 공백은 즉시 보고 대상입니다.

03

PROMETHEUS 감시

PROMETHEUS의 정보 작전, 기술 접촉, 비인가 개입을 추적합니다. 필요 시 저지, 격리, 무력화 절차를 검토합니다.

04

강원도 감시 구역

강원도 감시 구역의 이상 신호, 격리 대상, 연구 표본을 계속 추적합니다. 이변체는 연구, 격리, 감시 단계로 분리해 처리합니다.

05

외부 유입 SPEC 통제

중국, 북한, 해안가 등 자국 외부 경로에서 유입되는 SPEC과 오염 흔적을 식별하고 NADL 및 해안 감시망과 연계해 차단합니다.

지휘 평가 4대 지표

지휘 판단에 따라 변동하는 핵심 운용 지표. 어느 지표든 0에 도달하면 임무 실패로 분류됩니다.

C / CONTAINMENT

봉쇄

봉쇄선 유지 수준. 0 도달 시 시설 자체 봉쇄 및 기지 폐기 절차가 개시됩니다.

R / RESOURCES

자원

식량, 의약품, 장비 재고 수준. 0 도달 시 기지 기능이 정지됩니다.

T / TRUST

신뢰

기지 인원의 지휘관 신뢰도. 0 도달 시 인원 이탈 및 지휘 체계가 붕괴됩니다.

O / EVALUATION

평가

ORACLE이 산출하는 지휘관 적합도. 0 도달 시 단말 접속이 차단되고 지휘권이 회수됩니다.
